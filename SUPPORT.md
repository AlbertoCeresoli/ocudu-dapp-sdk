# Support

Use the project issue tracker at <https://gitlab.com/ocudu/work_groups/wg2_ai_ran/ocudu-dapp-sdk/-/issues> for reproducible bugs and documentation problems. Include the SDK and OCUDU commit IDs, compiler and CUDA versions, target GPU, build options, failing command, and minimal logs. Remove credentials, subscriber identifiers, and other sensitive deployment data.

Questions about integration should start with [docs/README.md](docs/README.md), the [quickstart](docs/ocudu_dapp_quickstart.md), and the [validation ladder](docs/validation_ladder.md).

This public source release does not imply an SLA, hardware availability, OTA access, or commercial support. Security reports follow [SECURITY.md](SECURITY.md).
